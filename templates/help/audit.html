{% trans "What gets recorded" %}

{% blocktrans %}Every sensitive or write action in the app — creating or editing a person, changing a lifecycle status, issuing equipment, locking a financial month, deciding a blacklist case, and many more — is recorded as an audit event: who did it, what it was, and when.{% endblocktrans %}

{% trans "Append-only" %}

{% blocktrans %}Audit events cannot be edited or deleted once written, by design — the audit trail is a permanent record, not a working document.{% endblocktrans %}

{% trans "Reading the log" %}

{% blocktrans %}The Audit tab, visible to roles with audit access, lists events newest first with the actor, action, and target. An action's label is always shown in your current language; any free-text reason attached to an event is shown exactly as it was typed, in whatever language the person who wrote it used.{% endblocktrans %}
