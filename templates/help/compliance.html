{% trans "Certificates" %}

{% blocktrans %}A worker's certificates — health checks, forklift or crane licences, welding qualifications, and anything else — live on their person page. Recruiters, Coordinators, and Managers can add a certificate, optionally attaching a photo or PDF of the document itself, with an issue date and expiry date.{% endblocktrans %}

{% trans "Category icons" %}

{% blocktrans %}A small icon next to a worker's photo shows each certificate category they hold, tinted by how urgent it is: green or uncolored means valid, amber means expiring soon, red means already expired. If someone holds more than one certificate in the same category — a renewal, for example — the icon reflects whichever one is currently most relevant.{% endblocktrans %}

{% trans "The Compliance page" %}

{% blocktrans %}The Compliance tab lists every missing, expiring, or expired requirement across all workers in one place — both certificates and entry medical checks — so nothing has to be found one worker at a time. A number badge on the tab itself shows how many issues are currently open.{% endblocktrans %}
