{% trans "What the blacklist is for" %}

{% blocktrans %}The blacklist prevents a specific person from being re-entered into the system after a serious issue — it's a last-resort control, decided case by case, not an automatic outcome of any other action.{% endblocktrans %}

{% trans "Proposing a case" %}

{% blocktrans %}A Coordinator or Manager proposes a case against a person, choosing a category and writing a reason. A proposed case is not yet in effect — it sits in the review queue until a Manager decides it.{% endblocktrans %}

{% trans "Deciding a case" %}

{% blocktrans %}A Manager reviews each proposed case and either approves it — which blocks that person from re-entry — or rejects it, which discards the proposal without blocking anyone. Every decision is recorded with who made it and why.{% endblocktrans %}

{% trans "Matching" %}

{% blocktrans %}New intake candidates are automatically checked against approved blacklist entries using a privacy-preserving matching technique, so a returning blocked person is flagged before they're re-added, without the system storing their raw identifying details in a searchable form.{% endblocktrans %}
