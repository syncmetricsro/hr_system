{% trans "Creating a feedback link" %}

{% blocktrans %}A feedback link is a tokenized, public web address — no worker account or login involved — optionally tied to a specific project. Each link gets its own QR code automatically, so it can be shared as a URL or scanned from a printed flyer.{% endblocktrans %}

{% trans "The printable flyer" %}

{% blocktrans %}Next to each link's on-screen QR code, "Download PDF" produces a one-page, printable flyer combining the QR code with the link's label — ready to print and post somewhere workers will see it.{% endblocktrans %}

{% trans "Reviewing submissions" %}

{% blocktrans %}Submissions are anonymous and appear in the Feedback inbox, newest first, each showing its message, an optional rating, and which link it came from. Only Managers can view the inbox. Submissions are retained for a limited window and purged automatically after that.{% endblocktrans %}
