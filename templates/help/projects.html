{% trans "Assigning a worker" %}

{% blocktrans %}Coordinators and Managers assign a worker to a project from the project's detail page or the worker's own record. An assignment tracks which project a person is currently placed on and feeds directly into Reports' per-project headcount.{% endblocktrans %}

{% trans "Readiness pillars" %}

{% blocktrans %}Each worker heading toward activation has a readiness record covering a fixed set of pillars — things like entry medical clearance, accommodation, and any project-specific requirements. A pillar can be marked complete, or marked not applicable with a reason. Activation stays blocked until every required pillar is either complete or explicitly marked not applicable.{% endblocktrans %}

{% trans "Exits" %}

{% blocktrans %}When a worker leaves a project, record their exit from the project or person page. Exiting reconciles anything they still hold — an assigned room, issued equipment — so those resources become available again, and moves the worker's status to Inactive with the exit reason on file.{% endblocktrans %}
