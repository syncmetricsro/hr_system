{% trans "The positive-sign convention" %}

{% blocktrans %}Every amount in Finance is entered and displayed as a positive number — revenue and cost both. Net (revenue minus cost) is calculated automatically wherever it's shown; it is never entered directly and never hardcoded, so it always matches its underlying line items.{% endblocktrans %}

{% trans "Recording a month" %}

{% blocktrans %}A financial month belongs to one project and one calendar month, built up from individual line items by category (a revenue source, a cost category). Add or edit line items until the month reflects reality, then let the month total recompute — it's always derived from its line items, never typed in as a single number.{% endblocktrans %}

{% trans "Locking and reopening" %}

{% blocktrans %}Once a month is finalized, a Manager can lock it, which prevents further edits to its line items. A locked month can be reopened if a correction is genuinely needed — both locking and reopening are recorded in the audit trail with whoever performed them.{% endblocktrans %}

{% trans "Reading the reports" %}

{% blocktrans %}The Finance tab's summary, yearly trend, and month-detail views all read the same underlying line items — a monthly trend chart, a margin gauge, and a category breakdown, all computed dynamically rather than stored separately, so they can never drift out of sync with each other.{% endblocktrans %}
